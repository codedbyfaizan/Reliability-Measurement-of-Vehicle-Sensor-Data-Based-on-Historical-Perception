# Reliability Measurement of Vehicle Sensor Data Based on Historical Perception

> A system that scores how trustworthy each vehicle sensor reading is by comparing it against historical perception data, temporal behaviour, and cross-sensor agreement.

## Project Overview
Modern vehicles depend on sensors (camera, LiDAR, radar, GPS, IMU, ultrasonic, wheel-speed) for ADAS and autonomous driving. Sensor data can be degraded by weather, dirt, hardware ageing, interference or malicious tampering. This project measures the **reliability of sensor data in real time** by using *historical perception* — what the sensors have previously observed at the same place, under similar conditions — as a reference baseline.
